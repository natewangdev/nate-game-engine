# Data Model: nge2 MVP Core Engine

**Feature**: `001-nge2-mvp` | **Date**: 2026-09-26

Chinese companion: [`data-model.zh-CN.md`](./data-model.zh-CN.md).

In-process entities only (no persistence DB).

## Entities

### NGE2 (Engine)

| Field | Type | Rules |
|-------|------|-------|
| resource_dir | path | Required; relative → resolve vs process cwd |
| capture_backend | `"dxcam"` \| `"mss"` | Default `"dxcam"`; must succeed at construct |
| hwnd | int \| None | Optional window binding |
| humanize | bool | Default `True` |
| control_mode | int | Default `2`; `0`/`1` → construct fail; `2` → open HID |
| closed | bool | After `close()` / `with` exit → True; further ops fail |

**Relationships**: owns one CaptureSession, one ControlSession (mode 2), WindowBinding, LogContext reference.

**Lifecycle**: `construct` → `active` → `closed`. From active, `capture.release` does not close engine. From closed, must create a new instance.

### CaptureSession

| Field | Type | Rules |
|-------|------|-------|
| backend_name | str | Matches engine choice |
| active | bool | False after `release()` until next `grab()` recreates |
| last_frame | ndarray \| None | Optional cache; not required by spec |

**Operations**: `grab(region=None) → BGR ndarray`; `release()`.

### ControlSession (HID)

| Field | Type | Rules |
|-------|------|-------|
| port | str | Auto-discovered or busy-fail |
| pointer_pos | (float, float) | Tracked screen pixels (device cannot query) |
| screen_size | (int, int) | Primary metrics for HID absolute mapping |
| humanize | bool | Copied from engine |

**Operations**: `move`, `left_click`, `right_click`, `move_and_click`, `key_click`, `key_down`, `key_up`.

### WindowBinding

| Field | Type | Rules |
|-------|------|-------|
| hwnd | int \| None | Bound at construct |
| title | str | Queried live when requested |
| client_rect_local | (l,t,r,b) | Client area in client coords |
| client_rect_screen | (l,t,r,b) | Screen physical pixels via ClientToScreen |

### HumanizePath

| Field | Type | Rules |
|-------|------|-------|
| waypoints | list[{x,y,delay}] | Generated by geom when humanize on |
| spread | float | Disk radius for final target scatter |

### KeyBinding

| Field | Type | Rules |
|-------|------|-------|
| name | str | Case-insensitive friendly name |
| usage_id | int | HID Usage Page 0x07 id |
| modifiers | bitmask | Optional for chords |

### StubModule (find / ocr / yolo)

No durable state; capability methods raise `NotImplementedError`.

## Validation Rules

- `resource_dir` missing/empty → construct fail
- Invalid `capture` string → construct fail
- Backend factory failure → construct fail (no fallback)
- No ESP32-S3 port / port busy → construct fail (mode 2)
- Unknown key name → fail before serial write
- Invalid/destroyed hwnd on use → clear error
- Ops on closed engine → clear error

## State Transitions

```text
NGE2:  [construct OK] --> ACTIVE --close()/__exit__--> CLOSED
CaptureSession: ACTIVE --release--> IDLE --grab--> ACTIVE
HID port registry: free --open--> held --close--> free
```
