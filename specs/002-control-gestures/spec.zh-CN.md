# 功能规格：控制手势（拖拽、滚轮、双击、热键别名）

**功能分支**：`002-control-gestures`

**创建**：2026-09-27

**状态**：草稿

**输入**：用户描述：为 control 增加拖拽（按下-移动-抬起，默认左键）、按方向与格数滚轮（对齐旧 nge：delta ±1、钳制 ±127）、仅左键双击，以及正式化组合键 `key_click(*keys)` 与别名 `hotkey(*keys)`（不做 `"ctrl+c"` 字符串）。

> 英文权威版：[`spec.md`](./spec.md)。执行 Spec Kit 时忽略本中文版。

## 用户场景与测试 *(必填)*

### 用户故事 1 - 按住鼠标键拖拽指针（优先级：P1）

脚本作者需要从一点拖到另一点。调用一次拖拽：移到起点 → 按下鼠标键（默认左键）→ 按既有 move/拟人规则移到终点 → 抬起。

**优先级理由**：最高新增执行价值；把已有 move 与按下/抬起可靠组合成手势。

**独立测试**：mock HID（或真机）验证左右键拖拽：到达起点后按下、拖动中保持、终点抬起。

**验收场景**：

1. **给定**已构造引擎，**当**作者默认按键从 `(x1,y1)` 拖到 `(x2,y2)`，**则**到达起点后左键按下，按拟人规则移到终点并抬起。
2. **给定**已构造引擎，**当**作者选择右键拖拽，**则**同一序列使用右键。
3. **给定**绑定 hwnd 的引擎，**当**作者用客户区相对坐标拖拽，**则**起终点解释规则与 move 一致。
4. **给定** `humanize=False`，**当**作者传入 duration/spread 拖拽，**则**起终点瞬时跳转，duration/spread 不影响路径（与 move 相同）。

---

### 用户故事 2 - 按方向与格数滚动滚轮（优先级：P1）

脚本作者按离散格数向上/向下滚动，不移动指针。对齐旧 nge：正向上、负向下，一格=1，钳制安全范围。

**优先级理由**：常见自动化需求；公开 control 此前缺失。

**独立测试**：mock 记录上/下与多格命令；非法格数在发送前明确失败。

**验收场景**：

1. **给定**已构造引擎，**当**向上滚动 N 格（N≥1），**则**设备收到一次幅度为 N 的向上滚轮动作（受钳制）。
2. **给定**已构造引擎，**当**向下滚动 N 格，**则**设备收到一次幅度为 N 的向下滚轮动作（受钳制）。
3. **给定**已构造引擎，**当**格数不是正整数，**则**明确失败且不发送滚轮命令。
4. **给定**已构造引擎，**当**滚动，**则**滚动 API 本身不移动指针。

---

### 用户故事 3 - 鼠标左键双击（优先级：P2）

脚本作者在当前位置或移到目标后左键双击；两次完整左键点击，中间有短间隔。

**优先级理由**：常见 UI 模式；本功能仅左键。

**独立测试**：mock 显示两次左键与间隔；可选先移动再双击。

**验收场景**：

1. **给定**已构造引擎，**当**不带坐标双击，**则**在当前指针位置发生两次左键点击并有短间隔。
2. **给定**已构造引擎，**当**带目标坐标双击，**则**先按拟人规则移动再两次左键点击。
3. **给定**已构造引擎，**当**显式传入 hold 与/或 interval，**则**点击时长与两次点击间隔使用这些值。
4. **给定**已构造引擎，**当**作者在目标处（或当前位置）双击，**则**两次点击落在同一点，无随机目标散布。

---

### 用户故事 4 - 正式化组合键 key_click 与 hotkey 别名（优先级：P3）

脚本作者用多参数按键点击触发 Ctrl+C 等组合键。本功能将该能力定为正式组合键 API（不解析 `"ctrl+c"`），并提供行为相同的 `hotkey` 别名。

**优先级理由**：能力基本已有；锁定契约、文档与别名，避免第三套 API。

**独立测试**：mock 演练 `key_click('ctrl','c')` 与 `hotkey(...)`；未知键发送前失败。

**验收场景**：

1. **给定**已构造引擎，**当**作者以修饰键+主键调用 `key_click`，**则**设备收到对应组合键。
2. **给定**已构造引擎，**当**作者以相同参数调用 `hotkey`，**则**行为与 `key_click` 一致。
3. **给定**已构造引擎，**当**仅使用 `*keys` 形式，**则**API 接受并文档化该形式为支持的组合键写法。

---

### 边界情况

- 拖拽在按下后失败：关闭时 STOP **必须**释放按住的键；作者仍应尽量完整完成拖拽。
- 滚轮格数超出钳制：幅度**必须**钳制到旧库安全范围（±127），不得回绕。
- 双击只提供 `x` 或只提供 `y`：**必须**明确失败（二者都给或都不给）。
- `hotkey` / `key_click` 无键名：**必须**明确失败。
- 拖拽/双击坐标规则与 move 相同；无效 hwnd 明确失败。

## 需求 *(必填)*

### 功能需求

- **FR-001**：`control` **必须**提供 `drag(x1, y1, x2, y2, *, button="L", duration=None, spread=10.0)`：移到起点 → 按下所选鼠标键 → 按与 `move` 相同的拟人/duration/spread 规则移到终点 → 抬起。默认左键；**必须**支持右键。默认 `spread` **必须**与 `move` 一致（10.0）。
- **FR-002**：按下与拖动移动之间**必须**有与现有点击一致的短拟人停顿（数十毫秒量级）。
- **FR-003**：`control` **必须**提供 `scroll(direction, notches=1)`，`direction` 为 `"up"`|`"down"`，`notches` 为正整数。向上为正 delta、向下为负；一格=1；有符号 delta **必须**钳制到 [-127, 127]（旧 nge）。滚动**不得**移动指针。非法方向或非正格数**必须**在发送前失败。
- **FR-004**：滚轮**必须**作为本功能必需的 HID 能力（由可选文档升为 `scroll` 使用的必需命令）。
- **FR-005**：`control` **必须**提供仅左键的 `double_click(x=None, y=None, *, hold=None, interval=None, duration=None)`。`x,y` 都给则先 move；都省略则原地双击。**必须**在**同一指针位置**发出两次完整左键点击（预移动与两次点击之间**不得**做落点散布/随机偏移）。省略 `interval` 时用短随机间隔；省略 `hold` 时用既有点击 hold 默认。`double_click` **不得**接受或应用 `spread`。
- **FR-006**：`key_click(*keys, hold=None)` 仍为正式组合键 API（分参数键名）。本功能**不得**要求或文档化 `"ctrl+c"` 这类合并字符串。
- **FR-007**：`control` **必须**提供与 `key_click` 行为相同的 `hotkey(*keys, hold=None)` 别名。
- **FR-008**：拖拽与双击目标坐标解释**必须**与既有 move/click 规则一致。
- **FR-009**：自动化测试**必须**用 mock HID 覆盖这些 API；真机 smoke 可选。
- **FR-010**：关闭引擎（或 close 时 STOP）**必须**继续释放按住的鼠标键，避免未完成拖拽卡键。

### 关键实体

- **DragGesture**：起终点、按键、可选 duration/spread。
- **WheelScroll**：方向、格数；一次发送钳制后的有符号 delta。
- **DoubleClick**：可选目标、hold、interval；两次左键。
- **KeyChord**：有序键名；`key_click` 与 `hotkey` 共用。

## 成功标准 *(必填)*

### 可度量结果

- **SC-001**：作者可按文档一次完成从 A 到 B 的默认左键拖拽，无需手写 down/move/up。
- **SC-002**：作者可一次调用按格数上/下滚动；非法格数 100% 在设备 I/O 前明确失败。
- **SC-003**：作者可用单次 API 在当前位置或移到目标后左键双击。
- **SC-004**：作者可通过 `key_click(*keys)` 与 `hotkey(*keys)` 触发文档化组合键且结果一致。
- **SC-005**：本功能的 mock HID 测试套件可在无物理设备的 CI 中通过。

## 假设

- 建立在 `001-nge2-mvp` 既有 control 表面之上。
- 滚轮极性与钳制对齐旧 `nate-gaming-engine` `controller.wheel`。
- 右键双击、水平/倾斜滚轮不在范围。
- `"ctrl+c"` 字符串解析不在范围。
- 拖拽停顿与双击间隔沿用既有「数十毫秒/随机拟人」风格。
- 固件已理解旧工具包所用滚轮与按键命令。

## 非范围

- OCR、YOLO、找图。
- 非 HID 前台/后台键鼠后端。
- 右键/中键双击。
- 滚轮左右倾斜。
- 新的组合键字符串 DSL。
- 除共享辅助外，不改变既有 `left_click` / `right_click` / `move_and_click` 语义。
