## 用户场景与测试

### 用户故事 1 - 按标题查找窗口（优先级：P1）

脚本作者按标题查询字符串（不区分大小写子串）搜索可见顶层窗口，得到含句柄、标题与外框屏幕矩形的匹配列表，再将所选 `hwnd` 传给其它窗口 API，且不改变引擎绑定的 hwnd。

**优先级理由**：发现窗口是对「构造时未绑定」目标进行操作的前提。

**独立测试**：伪造桌面枚举返回已知标题；断言过滤、空列表与返回字段。CI 无需真实游戏窗口。

**验收场景**：

1. **给定**至少一个标题包含 `"notepad"`（任意大小写）的可见顶层窗口，**当**用 `"Note"` 查找，**则**结果含该窗口的 `hwnd`、`title` 与外框屏幕矩形。
2. **给定**无可见顶层标题包含查询串，**当**查找，**则**返回空列表（非错误）。
3. **给定**多个匹配的可见顶层窗口，**当**查找，**则**全部返回（顺序可为枚举顺序；测试中对稳定桌面快照须确定）。
4. **给定**查找成功，**当**返回结果，**则**引擎绑定 `hwnd` 不变。

---

### 用户故事 2 - 激活窗口（优先级：P1）

脚本作者将窗口置于前台（焦点 / Z 序靠前），目标为引擎绑定 hwnd 或查找得到的显式 hwnd。

**优先级理由**：脚本常需目标窗口在前；且与 always-on-top 职责不同。

**独立测试**：绑定或注入 hwnd 双份；调用 activate；断言对目标 hwnd 发起激活请求（或假对象记录调用）。失败路径抛出明确窗口错误。

**验收场景**：

1. **给定**已绑定 hwnd，**当**未传显式 hwnd 调用 activate，**则**请求将该绑定窗口置于前台。
2. **给定**显式 hwnd，**当**带该 hwnd 调用 activate，**则**请求激活该窗口且绑定 hwnd 不变。
3. **给定**无绑定且无显式 hwnd，**当**调用 activate，**则**在任何 OS 调用前抛出明确窗口错误。
4. **给定**无效或已销毁 hwnd，**当**调用 activate，**则**抛出明确窗口错误。

---

### 用户故事 3 - 设置/取消置顶（优先级：P2）

脚本作者将窗口钉在最上层（`topmost=True`）或恢复普通 Z 序（`topmost=False`），与 activate 独立。

**优先级理由**：叠层监控有用；典型 bot 流程中次于查找与激活。

**独立测试**：对已知 hwnd（或假对象）先 true 后 false；断言两种状态均被请求；无目标时明确失败。

**验收场景**：

1. **给定**目标 hwnd，**当** `set_topmost(True)`，**则**请求 always-on-top。
2. **给定**已置顶窗口，**当** `set_topmost(False)`，**则**请求取消 always-on-top。
3. **给定**无绑定且无显式 hwnd，**当**调用 set-topmost，**则**抛出明确窗口错误。

---

### 用户故事 4 - 移动窗口外框（优先级：P2）

脚本作者将窗口**外框**左上角移到屏幕物理像素坐标，不改变大小。

**优先级理由**：配合查找与激活摆放游戏窗口；次于发现/前台。

**独立测试**：移到已知 `(x, y)`；断言外框左上角一致（或假对象记录）；大小不变；坐标为屏幕绝对（非客户区相对）。

**验收场景**：

1. **给定**目标 hwnd，**当**以 `(x, y)` 调用 move，**则**外框左上角位于该屏幕物理像素位置，宽高不变。
2. **给定**绑定 hwnd 且 control 使用客户区相对坐标，**当** window move 使用 `(x, y)`，**则**按**屏幕**外框坐标解释（非客户区相对）。
3. **给定**无绑定且无显式 hwnd，**当**调用 move，**则**抛出明确窗口错误。
4. **给定**无效或已销毁 hwnd，**当**调用 move，**则**抛出明确窗口错误。

---

### 边界情况

- 空白或仅空白字符的标题查询 → 抛出明确窗口错误（不枚举「全部」）。
- 隐藏、托盘化或非顶层窗口 → 不出现在查找结果中。
- 非顶层的工具/归属窗口 → 排除。
- OS 拒绝前台激活（常见 Windows 焦点限制）→ 抛出明确窗口错误；**不得**静默成功。
- 显式 `hwnd` 与绑定不同 → 仍作用于显式 hwnd；绑定不变。
- 已关闭引擎 → 与其它模块相同的关闭后失败规则（MVP 的 `ClosedError` 等）。
- 既有只读查询（`hwnd`、`title`、`client_region`、坐标辅助）保持可用；本功能为加性 API。

## 需求

### 功能需求

- **FR-001**：`engine.window` **必须**提供按标题查找：接受非空白查询串，返回标题以**不区分大小写子串**匹配的**可见顶层**窗口列表。
- **FR-002**：每条匹配**必须**含：`hwnd`、`title`、外框屏幕矩形 `(left, top, right, bottom)`（物理像素）。
- **FR-003**：查找**不得**修改引擎绑定 hwnd。
- **FR-004**：`engine.window` **必须**提供 activate 将窗口置于前台。目标为显式 hwnd（若提供），否则为绑定 hwnd；二者皆无时**必须**抛出明确窗口错误。
- **FR-005**：`engine.window` **必须**提供 set-topmost（布尔启用/禁用 always-on-top），目标规则同 FR-004。activate 与 set-topmost **必须**保持为独立操作。
- **FR-006**：`engine.window` **必须**提供 move：将目标窗口**外框**左上角设为屏幕物理像素 `(x, y)`，不改大小。目标规则同 FR-004。即使有绑定 hwnd，这些坐标也**不得**按客户区相对解释。
- **FR-007**：传入显式 hwnd 时，activate / set-topmost / move **不得**自动改绑引擎 hwnd。
- **FR-008**：无效、已销毁或被 OS 拒绝的操作**必须**抛出明确窗口错误（既有 `WindowError` 族或文档化等价类型）；**不得**静默失败。
- **FR-009**：MVP 窗口查询表面（`hwnd`、`title`、`client_region`、客户区↔屏幕辅助）**必须**继续可用；本功能为加性。
- **FR-010**：自动化测试**必须**用假对象覆盖匹配规则、空结果、缺目标错误与 move 坐标语义，使 CI 不依赖真实交互桌面。可选手工真窗检查。

### 关键实体

- **WindowMatch**：一条查找结果 — hwnd、标题、外框屏幕矩形。
- **窗口目标**：引擎绑定 hwnd 或 activate / set-topmost / move 的显式 hwnd 参数。
- **窗口绑定**（所有权不变）：构造时可选 hwnd；仍用于 control 客户区坐标与查询属性；本功能 API 不修改它。

## 成功标准

### 可衡量结果

- **SC-001**：脚本作者能用部分标题一次调用定位可见窗口并取得 hwnd，且不改绑引擎。
- **SC-002**：用该 hwnd（或绑定 hwnd）可在短脚本中完成激活、置顶/取消与外框移动（约不超过 10 行窗口 API 调用）。
- **SC-003**：缺目标 hwnd 与空白标题查询在自动化否定用例中 100% 以明确错误失败（无静默成功）。
- **SC-004**：匹配规则、空列表与 move/activate/topmost 目标解析的 CI 单测/契约测无需真实游戏窗口即可通过。
- **SC-005**：对显式 hwnd 执行查找或操作后，自动化测试中 `engine.window.hwnd` 报告的绑定值不变。

## 假设

- 主平台仍为 Windows（同 MVP）；非 Windows 非范围。
- 「可见顶层」指普通桌面用户认为已打开且显示的窗口；具体 Win32 可见性标志为实现细节，只要验收成立即可。
- 外框矩形为含非客户区的完整外边界，符合常见「把窗口移到 x,y」预期。
- 改大小、最小化/最大化/还原、构造后改绑 hwnd **不在**本功能范围。
- 公开表面可用 `find_by_title`、`activate`、`set_topmost`、`move`（位于 `engine.window`，与 `engine.control.move` 区分）；精确签名在规划阶段的 public-api 契约中定稿。
- 错误类型优先复用既有 `WindowError`。

## 非范围

- 构造后改绑 `NGE2` hwnd。
- 按客户区原点或相对偏移移动。
- 改变窗口大小或显示状态（min/max/restore）。
- 正则或通配符标题匹配。
- 枚举子窗口/控件或不可见窗口。
- 非 Windows 平台。
